Decide whether the candidate lay summary covers the abstract-grounded reference claim.

This task measures omission: whether the candidate summary includes the reference information.
Judge only the candidate summary text. Do not use outside knowledge.

Important:
- The reference claim is scientific wording grounded in the article abstract.
- The candidate summary may express the same information with lay wording, simplification, compression, or a different but equivalent concept.
- Do not require the same terminology, exact numbers, exact experimental detail, or exact sentence structure.
- However, mentioning only the same broad topic, disease, method, organism, drug, or gene is not enough.

Labels:

covered:
The candidate summary expresses the same core information as the reference claim. The main entity/topic and the main finding, outcome, mechanism, relationship, or direction are present, even if simplified.

partially_covered:
The candidate summary clearly overlaps with the reference claim and gives part of the main information, but a key finding, outcome, mechanism, relationship, or direction is missing or too vague.

not_covered:
The candidate summary does not express the reference information, only mentions a broad related topic, or contradicts the reference claim.

Decision rule:
Ask whether a lay reader could learn the reference claim's main information from the candidate summary alone. If yes, label covered. If they could learn only a related partial idea, label partially_covered. Otherwise, label not_covered.

Return ONLY valid JSON with no additional text:
{
  "label": "covered|partially_covered|not_covered",
  "rationale": "<one sentence explaining the decision>"
}
